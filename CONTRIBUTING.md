## izci contributing guidelines

<img width="500" alt="Bowl of vegetable beef barley soup to signify izci's codebase" src="https://github.com/user-attachments/assets/c429f352-0b18-4ce6-a2ce-f289a5dd5483" />

The above Wikimedia Commons public domain vegetable beef barley soup JPEG can be considered an accurate visual representation of the izci codebase.

AI/LLM-generated issues and PRs are fine. I vibecoded the entire thing anyway (woke up sweating one day and decided I wanted a website that played music and used some cute PWA APIs along the way). Refer to [AGENTS.md](https://raw.githubusercontent.com/tozworth/izci/refs/heads/main/AGENTS.md) for agent guidelines. Specifically, ensure the final output lacks 100-line legacy config adapters for a single renamed toggle, a window that proudly announces the removal of a feature and explains in several muted footnotes how it is no longer there, or an Options category that greets the user with a gigantic hero followed by individual settings presented as rectangular cards with slim colored borders and hover animations. The bar is very close to the floor here.

The developer firmly believes anyone who actually clicked on the contribution guidelines for an experimental libopenmpt PWA is a person with taste, and would already refrain from submitting such PRs.
