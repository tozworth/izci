The original izci-server code is licensed under MIT in LICENSE.md. Third-party modules and embedded assets retain their upstream licenses. The inventory below comes from the Linux amd64 CGO-disabled command dependency graph for cmd/izci-server; the separate Windows cmd/izci-desktop-signal graph is also identified. Platform-specific builds may contain fewer or different dependencies. Full upstream root license/notice files are reproduced below, including modernc musl and SQLite notices.

The server Docker recipe also installs Debian Bookworm packages, including FFmpeg and libopenmpt0. Those package licenses, additional bundled-library notices and copyright information remain in /usr/share/doc/<package>/copyright and /usr/share/common-licenses inside the image. FFmpeg has LGPL and GPL configurations; use the installed package copyright and ffmpeg -version/-L output for the particular image. Other Debian base-image packages retain their own licenses. FFmpeg and libopenmpt are system dependencies loaded/invoked by the server, not embedded by its CGO-disabled Go build.
